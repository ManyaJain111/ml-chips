\subsection{Reproducing the results}\label{sec:appreproduce}
Everything in this report is regenerated from the model file by the commands below (Python
\PythonVersion{}, dependencies pinned in \texttt{uv.lock}, simulator \SimVersion). All random draws
use the fixed seeds of \texttt{configs/project.yaml} (transistor data \SeedTransistorData, split
\SeedSplit, training \SeedTraining, corners \SeedCorners), so a rerun reproduces the same data,
models and results.
\begin{verbatim}
uv sync                                 # install the pinned environment
make check                              # ngspice, model file and versions
make all                                # scripts 00-12
uv run python report/make_numbers.py    # numbers, tables, zip
\end{verbatim}
\texttt{make\_numbers.py} also runs \texttt{report/make\_analysis.py}; no number in this report is
typed by hand. The two validation studies of Section~\ref{sec:gates} (SPICE oracle and fresh
corners) need several thousand extra ngspice runs and are rerun separately, as described in
\texttt{report/analysis/README.md}.
